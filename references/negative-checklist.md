# 负面清单（成稿前逐条自查）

成稿后按六类逐条过一遍，把命中项列入随稿的「校验清单」。**政治性、行文规则、格式硬伤、事实与占位**为必检硬项。

## 一、政治性与表述风险（硬项）
- [ ] 引用党中央/上级重要论述、决策部署是否**准确完整**，无断章取义、无错字漏字？拿不准处已留 `【待核对原文】`？
- [ ] 重大方针、政治定性、对外口径是否**未擅自发挥**，已提示核稿人/宣传/保密把关？
- [ ] 涉密信息是否按密级处理，公开发布件是否已剔除不宜公开内容？附注的公开属性是否标注？
- [ ] 机构、职务、人名、地名、排序是否规范准确？

## 二、文种与行文规则（硬项，对照 xingwen-rules.md）
- [ ] 文种是否选对（请示 vs 报告、通知 vs 意见、函 vs 请示、报告 vs 汇报材料）？是否用了法定文种，无"请示报告""报告的函""批示""汇报"之类？
- [ ] **请示**：一文一事？单一主送？未抄送下级？未夹带汇报？结尾有请示语？标注了签发人？
- [ ] **报告**：未夹带请示/请求事项？结尾未用"妥否，请批示""请批复"？
- [ ] **批复**：针对具体请示、态度明确？
- [ ] **函**：对象是不相隶属机关？称"贵局"、无命令口气？
- [ ] 上行文标注了**签发人**？下行文未误标签发人？
- [ ] 部门对下级政府（乡镇、街道）是否发了指令性要求？如经政府同意，文中是否注明"经县人民政府同意"？
- [ ] 是否越级行文？越级的是否抄送被越过的机关？是否直接送领导个人（横传直报）？
- [ ] 涉及其他部门职权的事项，是否已协商一致、需要会签的已提示？重要下行文是否抄送直接上级？
- [ ] 用户指定的违规结构，是否已按硬规则 1 纠正并在起草说明中写明？

## 三、格式与版式硬伤（硬项，对照 format-gbt9704.md）
- [ ] 标题=发文机关+事由+文种，无逗号等多余标点，事由未与文种重复，无"的通知的通知"？多行标题按词意断行、梯形或菱形？
- [ ] 发文字号：`代字〔年份〕序号`，六角括号、年份全称、序号无虚位无"第"？
- [ ] 主送机关顶格、规范称谓、末尾全角冒号？
- [ ] 成文日期：阿拉伯数字、年月日标全、月日无虚位、与署名一致？**与当前日期、签发和报送时间对得上**？
- [ ] 附件说明：1 个不编号、多个编 `1.` `2.` 分行，名称后无标点、无书名号，与附件本身名称和数量一致？
- [ ] 层次序数 `一、（一）1.（1）`，"1."用下脚点不用顿号，未越层？
- [ ] 署名、印章：按"加盖印章/不加盖印章"排法；未用"此页无正文"；函、请示等须盖章的未误写"可不盖章"？
- [ ] 附注在成文日期下一行、加圆括号？请示已注明联系人及电话（惯例）？
- [ ] 版记：抄送末尾句号；印发日期后加"印发"？

## 四、事实、数据与占位（硬项）
- [ ] 已发生的事实、数据、案例是否全部来自材料？材料没有的是否用 `【待补】` 占位，**未编造、未用【示意·待核】冒充实绩**？
- [ ] 统计实绩是确数不是区间？分项之和与总数一致？单位（万元/亿元）前后统一？同比、完成率的基数交代清楚？
- [ ] 同一数字在标题、导语、正文、附件多处出现时是否一致？
- [ ] 文号、文件名称拿不准的是否已占位，未凭记忆写？
- [ ] 相对时间（年底、明年）是否已推定为具体年月并提示核对？文中时限、用户说的报送日是否落在周末、节假日？
- [ ] 模板槽位 `【发文机关】` 之类是否已全部填实或换成三种占位符？占位符是否已全部汇总，关键项标 ★？
- [ ] 用户给的概数、化名、拿不准的机构名称是否已列入「须核实」？

## 五、内容与逻辑
- [ ] 缘由—事项—结语三段是否齐全、逻辑连贯？
- [ ] 任务是否落到**牵头/责任单位 + 时限 + 标准**（方案、意见、通知类）？
- [ ] 总结/汇报是否既讲成效也讲问题，打算与问题对应？
- [ ] 纪要是否只写议定事项，未把会上没定的内容补进去？
- [ ] 下行文是否穿靴戴帽、照搬上位文件？篇幅是否超过 5000 字（专项 4000 字）？

## 六、文风与文字
- [ ] 是否避免空话套话堆砌（"高度重视/切实加强"须有实招支撑）？
- [ ] 无口语、网络用语、生造词进入正式公文？
- [ ] 无长句缠绕、"的的不休"、一段到底？
- [ ] 数字、标点规范：统计用阿拉伯数字、成词概数用汉字；"截至"不误作"截止"；数值范围 `12%～15%`；时间起止用一字线？
- [ ] 简称是否首次全称后统一使用？
- [ ] 结尾语与文种匹配，未与开头重复（"现将……通知如下"后不再"特此通知"）？

---

**输出「校验清单」示例格式：**

```
【行文规则】✔ 一文一事、单主送县人民政府 ✔ 县财政局列抄送 ⚠ 原拟抄送各中小学已删（上行文不抄送下级）
【格式校验】
✔ 标题三要素齐全，分两行按词意断开
✔ 发文字号规范（武教〔2026〕15号），签发人与字号同行
⚠ 签发人待补 → 【待补：签发人】
【事实与数据】✔ 未编造数据 ⚠ 380万元为用户所给概数，须与附件测算表核平
【须核实】①"县自然资源局"是否为"县自然资源和规划局" ②会议年份按当前日期推定为2026年
【风险提示】涉及财政资金安排，须经本单位核稿人终审
【待补清单】★①改造学校数及测算明细 ②签发人 ③成文日期
```
