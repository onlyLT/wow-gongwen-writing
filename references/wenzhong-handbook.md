# 文种手册

依据《党政机关公文处理工作条例》（中办发〔2012〕14号）与政府机关行文惯例。**起草前先读对应条目**：确认「行文方向」和「结构骨架」，方向错、文种错是硬伤。文种速判表在 SKILL.md，谁能给谁发见 `xingwen-rules.md`。各条"适用"一行引自《条例》第八条原文。

## 目录

- **一、法定公文 15 种**——高频详解：1 通知 / 2 请示 / 3 报告 / 4 批复 / 5 函 / 6 意见 / 7 通报 / 8 纪要；低频简述：9 决定 / 10 命令 / 11 公告 / 12 通告 / 13 公报 / 14 议案 / 15 决议
- **二、事务性材料**——A 领导讲话稿 / A2 交流发言·表态发言 / B 工作总结 / B2 工作要点 / C 工作方案 / D 汇报材料 / E 调研报告 / F 政务信息·简报 / G 述职报告 / H 情况说明

行文方向说明：**上行文**=向上级（请示、报告、意见的报送）；**下行文**=向下级（通知、批复、通报、决定、命令、意见的印发）；**平行文**=不相隶属机关之间（函）。

篇幅约束（《整治形式主义为基层减负若干规定》，2024）：除部署综合性工作外，地方和部门文件一般不超过 5000 字，部署专项工作或具体任务的一般不超过 4000 字；开门见山，一般不阐述形势背景、重要意义、主要原则，确需的简明扼要；配套文件直接提具体落实措施，不简单照搬照抄上位文件；一般不提报送贯彻落实情况、制定配套文件的要求。

## 一、法定公文 15 种

### 政府口径高频（重点掌握）

#### 1. 通知（下行文 / 最高频）
- **适用**：发布、传达要求下级机关执行和有关单位周知或者执行的事项，批转、转发公文。（2012 版已无"任免人员""发布规章"——规章用命令（令）公布；任免实务中常用通知或决定。）
- **三种"发文件"的通知，别混用**：**印发**本机关制定的方案、办法、规划（"关于印发《××实施方案》的通知"）；**转发**上级机关和不相隶属机关的公文（"关于转发《…》的通知"）；**批转**下级机关的公文（"关于批转县发改局《…》的通知"，须有批转权限）。
- **结构骨架**：
  1. 开头——发文缘由/依据（"根据……""为……"）+ 引出事项（"现将……通知如下"/"现就……有关事项通知如下"）。印发/转发类一句话即可："现将《…》印发给你们，请认真贯彻执行。"
  2. 主体——分条列项写要求（事项、责任分工、时限、标准）。可用一、二、三或（一）（二）。
  3. 结尾——执行要求（"请遵照执行""请认真抓好落实"）或收尾语。
- **口径要点**：会议通知须含时间、地点、参会人、议程、报到方式、联系人；转发件不简单照转，确需发文的写明结合本地实际的具体要求，可不发的不发。
- **结尾语取舍**：正文最后一部分已是"工作要求"之类的收束段，不再加"特此通知"；开头用了"现将有关事项通知如下"的，结尾一般也不再用"特此通知"。
- **易错**：部门向下级政府发指令性通知（须"经县人民政府同意"或改由政府办公室发，见 xingwen-rules.md）；标题"的通知的通知"叠用；事项过多不分条；缺落实要求；报送时限落在周末或节假日。

#### 2. 请示（上行文 / 一文一事）
- **适用**：向上级机关请求指示、批准。**必须有明确请求，需上级批复。**
- **三种类型与结语**：请求**指示**型（政策界限不清、新情况怎么办）——"当否，请批示。"；请求**批准**型（要资金、项目、编制、审批事项）——"妥否，请批复。""以上请示，请予批准。"；请求**批转**型（本部门拟的意见需上级转发各地执行）——"以上意见如无不妥，请批转各地执行。"
- **结构骨架**：
  1. 请示缘由——为什么请示（背景、依据、问题、必要性），这是说服力所在，要充分。
  2. 请示事项——请求什么（具体、明确、可批复），"为此，特请示如下"。
  3. 结语——按上面类型选一句。
- **口径要点**：**一文一事**；**主送一个上级机关**，确需同时送其他机关的用抄送，**不得抄送下级**；**应当标注签发人**；联系人及电话写在附注处（惯例）；下级的请示需转报的，以本机关名义提出倾向性意见后上报，不原文转报；除领导直接交办的，不直接送领导个人。
- **资金类请示要点**（追加经费、专项资金、项目补助）：①写清已安排情况（年初预算有无、已拨付多少）与缺口怎么来的；②请求金额要有测算依据，测算表作附件，正文、附件、合计三处数字一致；③建议资金来源（追加预算、调剂、争取上级资金）；④说明绩效目标或预期效果，达到本地事前绩效评估门槛的另附评估材料；⑤用户给的是概数时，请示事项里写成确数（去掉"大概""约"——请求须明确可批），在校验清单提示与测算表核平；用户没说清是追加额还是总需求的，按追加额写、总需求另设【待补】；⑥下半年才申请当年追加的，说明年内能否形成支出，支出会跨年的提示与财政部门沟通是否改列下年预算。需县政府决策的，请示县政府、抄送县财政局；只需财政部门办理的，改用函。
- **易错**：一文多事；多头主送；请示中夹带汇报大段工作（那是报告）；无明确请求事项；把对同级财政局的请求写成请示。

#### 3. 报告（上行文 / 陈述性，不要批复）
- **适用**：向上级机关汇报工作、反映情况，回复上级机关的询问。**陈述为主，不要求上级答复。**
- **结构骨架**：
  1. 报告缘由/概述——总述基本情况或缘由。
  2. 报告事项——工作进展、成效、问题、下一步打算；或情况的来龙去脉。
  3. 结语——"特此报告。""专此报告，请审阅。"
- **口径要点**：**不得在报告等非请示性公文中夹带请示事项**（要批准就另行请示，报告中可写"有关资金需求另文请示"）；工作报告重"数据+成效+问题+打算"四段式；有发文字号、走公文流转的就是法定报告，标签发人、原则上主送一个上级机关。
- **易错**：报告里藏请求，或结尾用"妥否，请批示""请批复"（等于变相请示，上级不批，事项就悬空）；标题写成"……的汇报"（汇报不是法定文种）；只报喜不报忧、无问题分析。

#### 4. 批复（下行文 / 答复请示）
- **适用**：答复下级机关请示事项。**有请示才有批复，被动行文。**
- **结构骨架**：
  1. 引据——"你局《关于……的请示》（×财〔2026〕5号）收悉。"（先引标题、后引文号，属惯例）
  2. 批复意见——同意/原则同意/不同意 + 具体意见、条件、要求。
  3. 结语——"此复。""请遵照执行。"
- **口径要点**：针对性强，请示什么答复什么；态度明确（同意与否）；批复事项涉及其他单位的，抄送相关单位。
- **易错**：答非所问；态度含糊；一份批复答复多个请示；生造"批示"文种。

#### 5. 函（平行文 / 不相隶属机关）
- **适用**：不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项（如向有审批权的主管部门请批）。
- **结构骨架**：
  1. 缘由——"因……""根据……"，简明交代。
  2. 事项——商洽/询问/请批的具体内容。
  3. 结语——去函："请予研究函复。""请予支持为盼。""特此函商。"；复函："特此函复。""此复。"
- **口径要点**：平行或不相隶属机关首选文种；称对方"贵局""贵单位"，自称"我局"；语气平和商洽，请批函也不用"请批示"；去函与复函对应，复函开头引来函："贵局《关于……的函》收悉。"；函须盖章，不属于免盖章情形；常用信函格式（见 format-gbt9704.md 第七节）。
- **易错**：对不相隶属机关用"请示/批复"（应用函）；语气生硬命令；结尾用私人书信的"此致 敬礼"。

#### 6. 意见（上行/下行/平行皆可）
- **适用**：对重要问题提出见解和处理办法。
- **结构骨架**：
  1. 缘由/背景——形势、依据、必要性（下行意见按减负要求从简）。
  2. 总体要求——指导思想、基本原则、目标（下行意见常有）。
  3. 主要举措——分条写措施、任务、分工。
  4. 保障/落实——组织领导、责任、督查。
- **口径要点**：下行"实施意见/指导意见"是政策落地主力文种，重"举措+分工+保障"；文中有明确执行要求的下级应遵照执行，无明确要求的可参照执行。上行意见结尾可写"以上意见，请审示"，并按请示的程序和要求办理（惯例，依据为国办函〔2001〕1号，《条例》未作规定）。
- **易错**：只有原则无具体举措；分工不落到部门；涉及其他部门职权的未协商一致就行文。

#### 7. 通报（下行文）
- **适用**：表彰先进、批评错误、传达重要精神和告知重要情况。
- **结构骨架**：
  1. 事实——发生了什么（表彰/批评的事实经过、典型情况）。
  2. 评析/决定——定性、给予何种表彰或处理、原因剖析。
  3. 要求——号召学习/引以为戒/整改要求。
- **易错**：事实不清就下结论（批评通报的事实须经核实）；表彰/批评尺度失当；情况通报写成工作总结。

#### 8. 纪要（会议记载 / 特殊行文）
- **适用**：记载会议主要情况和议定事项。（2012 版文种名称为"纪要"。）
- **结构骨架**：
  1. 会议概况——时间、地点、主持人、议题（"会议听取了……研究了……"），引出"现将会议议定事项纪要如下："。出席、列席人员写在开头一段，或按国标排在文末名单，二者择一。
  2. 议定事项——逐项写会议形成的决定、共识、分工、时限（一、二、三分项）。
  3. 结尾——落实要求（可选；会上没有统一要求的不写）。
- **口径要点**：用第三人称"会议认为/会议决定/会议要求"，不用"我""你"；只写议定事项，不写发言实录；政府常务会议实行首长负责制，主持人拍板的即写成"会议要求/会议决定"；与会领导的补充意见、会上无异议的，可写"会议强调/会议指出"，不点名；**未形成决定的不写**；会上没有明确的（时限、金额、责任单位）**不补、不占位**，在校验清单提示"会上未明确"——议定事项以会议记录为限，会上没定的不是"缺失的事实"；版头、版记要素（县名、期号、印发日期）缺了照常用 `【待补】`。纪要一般不署名、不盖章（国标未规定，以本地细则为准），期号、印发单位和日期排在版头。
- **虚实结构法**（先虚后实）：议定事项每项先"虚"——用"会议认为/会议指出/会议强调"表达一致看法与定性；再"实"——用"会议明确/会议要求/会议议定"落具体事项（谁来做、做什么、什么时限）。会上没有定性内容的，不硬凑"虚"的部分。
- **易错（四忌）**：写成发言逐字稿；夹带未议定的个人意见；不概括归纳、内容杂乱；不恰当突出领导讲话，把纪要写成讲话传达稿。

### 政府口径低频（了解结构即可）

#### 9. 决定（下行文）
对重要事项作出决策和部署、奖惩有关单位和人员、变更或者撤销下级机关不适当的决定事项。结构：缘由（依据、意义）→决定事项（分条）→执行要求。

#### 10. 命令（令）（高层用）
公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖有关单位和人员。政府主要由行政首长签发，用命令格式（见 format-gbt9704.md）。基层少用。

#### 11. 公告（对外）
向国内外宣布重要事项或者法定事项。发布机关层级高、事项重大；基层单位日常告知、招标招聘等业务事项不要滥用"公告"文种（用通告、通知，或按业务规定的文书名称）。

#### 12. 通告（对外）
在一定范围内公布应当遵守或者周知的事项（如交通管制、征地、禁燃）。结构：依据→通告事项（分条）→施行日期/落款。

#### 13. 公报（高层用）
公布重要决定或者重大事项（如全会公报、统计公报）。基层几乎不用。

#### 14. 议案（政府向人大）
各级人民政府按照法律程序向同级人民代表大会或者人民代表大会常务委员会提请审议事项。有严格程序，须报请人大列入议程。

#### 15. 决议（会议通过）
会议讨论通过的重大决策事项，须经会议表决。结构：会议情况→决议事项→号召。**两种类型须区分**：**决策性决议**（就重大问题作决策）写"目标任务+措施方法"，可设小标题、结尾可有号召；**批准性决议**（审议批准工作报告，程序性）篇幅短小、一般不设小标题，多用"会议认为/会议号召"。类型选错则格式语气全错。

## 二、事务性材料（非法定，用量大）

无固定法定格式，但有成熟套路。政府口径重"实、准、新"。事务性材料需要正式报送时，一般用"通知"印发或随"报告"报送，不单独编发文字号。

### A. 领导讲话稿
- **场景**：会议讲话、部署动员、总结表彰、调研座谈。
- **结构骨架（部署类）**：
  1. 开头——点会议主题与重要性（"今天这个会，主要任务是……"）。
  2. 谈认识——为什么重要（讲形势、讲意义、统一思想）。
  3. 讲部署——怎么干（重点任务，分条，是主体，占篇幅最大）。
  4. 提要求——保障落实（加强领导、压实责任、严格督查，常"三点要求/四点希望"）。
  5. 结尾——号召鼓劲。
- **口径要点**：口语化、有节奏、可宣读；用"我讲三点意见"分层；数字案例增强说服；结合本地本单位实际。
- **易错**：通篇文件语搬运、无自己的话；空话套话堆砌；要求不具体。

### A2. 交流发言 / 表态发言
- **场景**：代表本单位在会上介绍经验（交流发言）或表明落实态度（表态发言），一般限时 5～8 分钟（约 1500～2500 字）。
- **结构骨架**：观点式标题 → 一两句点题 → 三条做法（每条：做法 + 数据成效 + 一个具体例子）→ 一两句下一步或"不当之处请批评指正"。表态发言改为：态度 → 具体举措与时限 → 表决心。
- **口径要点**：讲本单位独有的做法，不重复会议意义和上级部署；小标题成组对称（见 craft-principles.md）；与领导讲话稿区分——不布置工作、不提要求。
- **易错**：写成工作总结的全面铺开；开头大段寒暄和形势；做法没有例子和数据。

### B. 工作总结（年度/专项）
- **结构骨架**：
  1. 总体概述——一年/一项工作的总背景与总评价。
  2. 主要做法与成效——分板块写"做了什么+成效数据"（主体）。
  3. 存在问题——客观找差距（不可省，也不可空泛）。
  4. 下一步打算/明年思路——针对性举措。
- **口径要点**：成效用数据说话、可对比（同比/完成率）；做法要提炼"经验点"；问题要真、打算要实。
- **易错**：流水账、无提炼；只报喜不谈问题；打算与问题不对应。

### B2. 工作要点
- **场景**：年度或阶段工作的提纲式安排，常以通知印发。
- **结构骨架**：开头一段总体要求（指导思想 + 总目标 + 主要预期指标）→ 分板块列任务，每条一句一事、动宾开头，括注牵头单位。
- **口径要点**：只写"干什么、达到什么"，不写意义、不展开做法；条目可量化的量化；与工作方案区分——要点管全年多项工作，方案管一项工作的分工步骤。
- **易错**：写成总结或方案；条目笼统（"进一步加强××"）无抓手。

### C. 工作方案 / 实施方案
- **结构骨架**：
  1. 指导思想/总体要求——依据、目标（可含总体目标+具体目标）。
  2. 工作任务/主要举措——分条，每条含具体内容、牵头单位、责任单位、完成时限。
  3. 实施步骤/阶段安排——动员部署、组织实施、总结验收（阶段+时间节点）。
  4. 保障措施——组织领导、经费保障、宣传引导、督查考核。
- **口径要点**：**任务必须落到牵头/责任单位和时限**，可附任务分解表；目标可量化；以通知印发（"关于印发《××工作方案》的通知"）。
- **易错**：任务无分工、无时限（不可操作）；步骤与任务脱节。

### D. 汇报材料（工作/情况汇报）
- **场景**：会上口头汇报、领导调研座谈、检查考核时提供，不编发文字号。要走公文流转、编文号上报的，用"报告"。
- **结构骨架**：基本情况→主要做法与成效→存在困难问题→下一步打算（+ 需上级支持事项，另起说明）。
- **口径要点**：面向听汇报对象裁剪重点；"需支持事项"要具体（要政策/要资金/要项目）；口语可读。
- **三多三少**：少讲过程（开了几次会一句带过）、多讲实质（直接说成效结论问题）；少讲空话（"在上级正确领导下"可删）、多讲实话（数字案例支撑）；少讲一般（人人都做的常规动作）、多讲重点特色（本地独特做法亮点）。
- **易错**：面面俱到无重点；把汇报写成总结。

### E. 调研报告
- **结构骨架**：调研背景与方法→现状与成效→问题及原因分析→对策建议（主体，分条，可操作）。
- **口径要点**：用一手数据和案例；问题剖析要透（体制机制层面）；建议要有针对性、可落地。
- **易错**：有情况无分析、有问题无建议；建议空泛喊口号。

### F. 政务信息 / 简报
- **结构骨架**：标题（观点式，突出亮点）→导语（一句话概括：谁、做了什么、有何成效）→主体（做法+成效，短小精悍）→报送栏。
- **口径要点**：**短、快、新**，一事一报，300–800 字为宜；突出可上报的亮点、经验、动态；用**第三人称**（"××县""县财政局"），不用"我县""我局"——信息会被上级采编；报送单位、审核签发人、联系人等栏目以上级信息报送模板为准。
- **三种类型**：经验类（标题=做法+成效，正文"怎么做的→数据成效"）；建议类（标题=问题+对策，正文"问题现状→原因→对策一一对应"）；问题类（标题=事件+影响，正文"事实经过→性质→初步处理→启示"）。
- **数据拿不到时**：不编数（SKILL.md 硬规则 2）；数据不全的可改报"动态类"信息（只写上线时间、做法），待数据齐了再报成效。
- **易错（三忌）**：太长、像工作总结（信息要提炼观点不是流水账）；标题模糊（要一眼看出说什么）；空洞无据（每个判断要有数据或事实支撑）。

### G. 述职报告
- **结构骨架**：履职总述→德能勤绩廉分述（重点绩：干了什么、成效）→不足与改进→表态。
- **口径要点**：第一人称、实事求是、成绩具体、不足真诚。

### H. 情况说明
- **场景**：就某一事项（信访、审计或巡察发现的问题、媒体反映、上级询问）向上级或有关方面讲清来龙去脉。
- **结构骨架**：说明缘由（应××要求/针对××问题）→ 基本情况（事实经过，只陈述不评论）→ 原因分析 → 处理情况与下一步措施。
- **口径要点**：事实准确是第一位，时间、数字、涉及对象逐项可核；不回避问题，也不主动扩大；需要上级决定的事项另行请示，不在说明里提。
- **易错**：避重就轻、只讲客观原因；夹带请求事项；事实与原因混写。
