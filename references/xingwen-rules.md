# 行文关系与行文规则

依据《党政机关公文处理工作条例》（中办发〔2012〕14号）第四章"行文规则"（第十三～十七条）。SKILL.md 第 2 步必读：先判"谁给谁发、能不能发"，再定文种。违反本文件任一条，都按 SKILL.md 硬规则 1 直接纠正。

## 一、行文关系判定（县级政府口径示例，其他层级类推）

| 发文方 → 收文方 | 关系 | 用什么 | 要点 |
|---|---|---|---|
| 县直部门 → 县人民政府 | 隶属，上行 | 请示 / 报告 / 意见 | 标签发人；原则上主送一个；不抄送下级 |
| 县政府工作部门 → 县委 | 业务工作不直接主送县委 | 主送县人民政府，县委需知悉的抄送县委办公室 | 属党的工作、县委交办事项的，以部门党组（党委）名义向县委报送 |
| 县直部门 → 市级对口主管部门 | 业务领导/指导，上行 | 请示 / 报告 | 重大事项须经县政府同意或授权；本部门职权内事项直接报 |
| 县直部门 ↔ 其他县直部门（含财政、发改等审批部门） | 不相隶属，平行 | **函**（商洽、询问、请批） | 用"请示""报告"是硬伤 |
| 县直部门 → 乡镇人民政府、街道办事处 | 不相隶属（对方是下级**政府**） | 不得发指令性公文、不得在文中提指令性要求 | 需要布置的：报县政府同意后以部门名义发，文中注明"经县人民政府同意"；或代拟由县政府办公室发 |
| 议事协调机构（××领导小组及其办公室）→ 乡镇人民政府、街道办事处 | 同上 | 同上，不得发指令性公文 | 《整治形式主义为基层减负若干规定》（2024）明文重申 |
| 县直部门 → 乡镇（街道）对口站所 | 职权范围内业务指导，下行 | 通知等 | 限本部门职权范围 |
| 县政府办公室 → 乡镇（街道）、县直部门 | 经县政府授权，下行 | 通知 / 意见等 | 重要行文抄送市政府办公室等直接上级 |
| 乡镇人民政府 → 县人民政府 | 隶属，上行 | 请示 / 报告 | 同上行文规则 |
| 乡镇人民政府 → 县直部门 | 不相隶属 | 函 | |
| 部门内设科室 → 本部门以外 | — | 不得对外正式行文 | 办公室（厅）除外；需对外的以部门名义发 |

受双重领导的机关（如县直部门同时受县政府和市主管局领导）：向一个上级机关行文，必要时抄送另一个上级机关。

## 二、行文规则要点（按条例条文）

**第十三条 必要性**：行文应当确有必要，讲求实效，注重针对性和可操作性。能不发的不发、能短的不短（为基层减负要求同）。

**第十四条 隶属与越级**：行文关系根据隶属关系和职权范围确定。一般不得越级行文；特殊情况需要越级的，应当同时抄送被越过的机关。

**第十五条 向上级机关行文**：
1. 原则上主送一个上级机关，根据需要同时抄送相关上级机关和同级机关，**不抄送下级机关**。
2. 党委、政府的部门向上级主管部门请示、报告重大事项，应当经本级党委、政府同意或者授权；属于部门职权范围内的事项应当直接报送上级主管部门。
3. 下级机关的请示事项，如需以本机关名义向上级机关请示，应当提出倾向性意见后上报，**不得原文转报**上级机关。
4. 请示应当**一文一事**。不得在报告等非请示性公文中夹带请示事项。
5. 除上级机关负责人直接交办事项外，不得以本机关名义向上级机关负责人报送公文，不得以本机关负责人名义向上级机关报送公文。
6. 受双重领导的机关向一个上级机关行文，必要时抄送另一个上级机关。

**第十六条 向下级机关行文**：
1. 主送受理机关，根据需要抄送相关机关。**重要行文应当同时抄送发文机关的直接上级机关**。
2. 党委、政府的办公厅（室）根据本级党委、政府授权，可以向下级党委、政府行文；其他部门和单位不得向下级党委、政府发布指令性公文或者在公文中向下级党委、政府提出指令性要求。需经政府审批的具体事项，经政府同意后可以由政府职能部门行文，**文中须注明已经政府同意**。
3. 党委、政府的部门在各自职权范围内可以向下级党委、政府的相关部门行文。
4. 涉及多个部门职权范围内的事务，部门之间未协商一致的，不得向下行文；擅自行文的，上级机关应当责令其纠正或者撤销。
5. 上级机关向受双重领导的下级机关行文，必要时抄送该下级机关的另一个上级机关。

**第十七条 联合行文与部门行文**：同级党政机关、党政机关与其他同级机关必要时可以联合行文。属于党委、政府各自职权范围内的工作，不得联合行文。党委、政府的部门依据职权可以相互行文。部门内设机构除办公厅（室）外不得对外正式行文。

联合行文：由所有联署机关的负责人会签（第二十二条）；发文字号只标主办机关的；成文日期署最后签发机关负责人签发的日期；署名、印章按联署机关排列，主办机关在前（详见 format-gbt9704.md）。

**2024 年减负规定的叠加要求**（《整治形式主义为基层减负若干规定》一、切实精简文件）：发文实行计划管理、总量管控；议事协调机构、部门和单位不得向下级党委和政府发布指令性公文或者在公文中提出指令性要求；不得以"红头"变"白头"、正式改便笺等方式规避发文管理；一般不提出报送贯彻落实情况、制定配套文件的要求。

## 三、"用户指定即违规"的纠正对照

| 用户要求 | 直接改成 | 替代路径（写进起草说明） |
|---|---|---|
| 请示同时报县政府和县财政局 | 主送县人民政府，抄送县财政局 | —— |
| 请示/报告抄送各学校、各乡镇"让他们心里有数" | 删去对下级的抄送 | 上级批复后另发通知告知 |
| 部门给各乡镇人民政府发通知布置任务 | 正文开头注明"经县人民政府同意，"（提示须先报批），或改由县政府办公室发文 | 仅需对口站所落实的，可发给乡镇（街道）对口站所 |
| 报告末尾要钱、要政策 | 拆成报告 + 请示两份 | 报告中可写"有关资金需求另文请示" |
| 向县财政局写"请示"要追加经费 | 需县政府决策的：请示县人民政府、抄送县财政局；只需财政部门办理的：改用函 | 以本地预算追加程序为准，拿不准在起草说明提示 |
| 以局名义给县长个人报送材料 | 主送县人民政府 | 领导直接交办的事项除外 |
| 把乡镇的请示原文转报县政府 | 以本部门名义重写请示，提出倾向性意见 | 乡镇请示作附件 |
| 两个部门意见未统一就要联合发文 / 向下发文 | 先会签协商一致 | 在起草说明提示"须会签" |
| 科室以科室名义对外发函 | 改以部门名义发 | 办公室除外 |
