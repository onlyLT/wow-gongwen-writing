# 法定公文骨架模板（大纲加速起点）

用于工作流第 3 步"先出大纲"。`【…】` 是写作槽位：出稿时要么填实，要么换成 SKILL.md 的三种占位符之一，不得原样留在成稿里。`▍` 是版式位置标签，成稿中照用。

## 通知（下行）
```
▍标题  【发文机关】关于【事由】的通知
▍主送  【各乡镇人民政府、街道办事处，县政府各部门】：
       （部门发给乡镇政府的，开头须写"经县人民政府同意，"——见 xingwen-rules.md）

  【依据/目的：根据…／为…】，现将【事项】通知如下：

  一、【事项一：内容+要求】
  二、【事项二：责任分工/标准】
  三、【工作要求：时限、落实】        ← 以工作要求收束的，不再加"特此通知"

▍署名  【发文机关】
       【成文日期】
▍附注  （【公开属性，如"此件公开发布"】）
```

## 印发 / 转发通知（下行，发文件用）
```
▍标题  【发文机关】关于印发《【文件名称】》的通知
       （转发上级：关于转发《…》的通知；批转下级：关于批转【下级机关】《…》的通知）
▍主送  【各有关单位】：

  《【文件名称】》已经【县政府同意／局党组会议研究通过】，现印发给你们，请认真贯彻执行。
  （转发的：确需发文时写一两条结合本地实际的具体要求，不简单照转）

▍署名  【发文机关】
       【成文日期】
  （被印发的文件另起一页排在后面，不再列附件说明）
```

## 请示（上行，一文一事，单主送，标签发人）
```
▍版头  【发文机关】文件
       【代字〔2026〕×号】                      签发人：【姓名】
▍标题  【发文机关】关于【请求事项】的请示
▍主送  【一个上级机关】：

  【请示缘由：背景、依据、必要性、问题——写充分，是说服核心】。
  （资金类：已安排情况 → 缺口怎么来 → 测算依据 → 资金来源建议 → 预期效果）

  为此，特请示如下：【明确、具体、可批复的请求事项】。

  妥否，请批复。（请求批准）／当否，请批示。（请求指示）

▍附件说明  附件：【测算表等，名称后不加标点】
▍署名  【发文机关】
       【成文日期】
▍附注  （联系人：【姓名】　联系电话：【电话】）
▍版记  抄送：【相关上级或同级机关，不抄送下级】。
       【印发机关，一般为本机关办公室】                【印发日期】印发
```

## 报告（上行，陈述性，不夹带请示）
```
▍版头  【发文机关】文件
       【代字〔2026〕×号】                      签发人：【姓名】
▍标题  【发文机关】关于【事项】的报告
▍主送  【一个上级机关】：

  【概述/缘由】。现将有关情况报告如下：

  一、【工作进展与成效（数据）】
  二、【存在的问题】
  三、【下一步打算】                 ← 要资金、要政策的另行请示，此处可写"有关事项另文请示"

  特此报告。

▍署名  【发文机关】
       【成文日期】
```

## 批复（下行，答复请示）
```
▍标题  【发文机关】关于【事由】的批复
▍主送  【请示单位】：

  你【局/单位】《关于【…】的请示》（【代字〔年份〕×号】）收悉。经研究，现批复如下：

  【同意/原则同意/不同意 + 具体意见、条件、要求】。

  此复。

▍署名  【发文机关】
       【成文日期】
```

## 函（平行，不相隶属机关）
```
▍标题  【发文机关】关于【商请／商洽／询问】【事由】的函
▍主送  【对方机关】：

  【缘由：因…／根据…】。现就【事项】函商如下：【具体事项】。

  请予研究函复。（复函开头："贵局《关于…的函》收悉。"结尾："特此函复。"）

▍署名  【发文机关】（函须盖章）
       【成文日期】
```

## 通报（下行，表彰/批评/情况）
```
▍标题  【发文机关】关于【表彰×××／×××问题】的通报
▍主送  【各乡镇人民政府、街道办事处，县政府各部门】：

  【事实：表彰/批评的事实经过、典型情况——写清楚再定性】。

  【评析/决定：定性 + 给予何种表彰/处理 + 原因剖析】。

  【要求：号召学习／引以为戒、整改要求（分条）】。

▍署名  【发文机关】
       【成文日期】
```

## 意见（下行，实施/指导意见）
```
▍标题  【发文机关】关于【事由】的实施意见
▍主送  【各责任单位】：

  【依据与目的，一两句——不铺陈形势意义】。经研究，提出如下意见。

  一、总体要求（目标，可量化）
  二、主要任务（分条，每条含内容+牵头/责任单位+时限）
  三、保障措施（组织领导、经费、督查考核——精炼）

▍署名  【发文机关】
       【成文日期】
```

## 纪要（第三人称，一般不署名、不盖章）
```
▍版头  【××县人民政府常务会议】纪要
       【〔2026〕×号／第×期】
       【××县人民政府办公室】                      【印发日期】

  【×年×月×日】，【主持人职务、姓名】在【地点】主持召开【会议】，【听取了…研究了…】。现将会议议定事项纪要如下：

  一、关于【议题一】
     会议认为，【一致看法/定性——会上没有就不写】。会议要求，【谁、做什么、何时完成】。
  二、关于【议题二】
     会议同意【…】。会议明确，由【牵头单位】牵头、【配合单位】配合，【时限】前完成【…】。

▍出席  出席：【领导姓名，单位负责同志】
       列席：【…】
       请假：【…】
       （或把出席、列席写进开头一段，二者择一）
▍版记  分送：【分送范围】。
       （版头已标印发单位和日期的，版记只列分送，不再重复印发行）
```
